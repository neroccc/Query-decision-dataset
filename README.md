# Query-Decision Dataset

This dataset contains a collection of query-decision problems. Each folder corresponds to a specific problem type and includes the ground-truth graph along with a set of `(query, decision, decision value)` tuples computed from that graph.

- **Cut_dataset**: Minimum Cut problem.
- **DC_dataset**: Diffusion Containment problem.
- **DE_dataset**: Diffusion Enhancement problem.
- **Difference_maximization_dataset**: Difference Maximization problem.
- **Multicut**: Multicut problem.
- **SP_dataset**: Shortest Path problem.
- **Source_detection_dataset**: Source Detection problem.
- **Steiner_dataset**: Steiner Tree problem.
- **Effector_detection_dataset**: Effector Detection problem.
